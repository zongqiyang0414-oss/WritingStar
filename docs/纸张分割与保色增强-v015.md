# v0.15.0 · 纸张分割与保色增强 · 2026-10-30

用户图1、图2把纸张下方桌面也框了进去；图3提供了纸面干净、印刷框与文字清晰的增强参考。本轮修改检测依据和图像恢复流程，使用同一份源码支持H5与微信。

## 检测与跟踪

旧检测以灰度阈值、连通轮廓和四边拟合为主，候选按面积乘置信度排序。浅色木桌与阴影纸面亮度相近时，纸边可能弱于桌沿，导致四条不同物体的边被拼成更大的矩形。

新流程增加归一化色度特征和确定性的颜色聚类，让光照不同的纸面仍有机会归入同一材料区域，区分木桌、纸张及彩色物体。灰度和色度通道共同提供候选与物理边线；候选还需检查框内区域是否混入另一种材料。已有跟踪框也经过检查，避免只修首次识别、随后继续沿用错误下沿。

仍然要求观察到完整物理边界，不用纸内印刷框或猜测比例补出四角。不确定时交给原有四角调整流程；二维码识别、页序、同页锁和归档规则沿用。

## 纸面恢复

增强拆入`scanEnhancement.js`。按局部亮纸像素联合估计RGB纸面颜色与照明，排除彩色墨迹，补全被文字遮挡的照明场，再逐通道恢复反射颜色。这类Retinex式分解先处理色偏和阴影，再做连续色调及保守边缘增强。

封闭的局部暗灰区域单独保护，避免填满多个采样格的粗灰笔被误当成阴影提白。细灰阶保留淡铅笔，蓝笔与红章保留颜色，细印刷线与文字边缘保持可辨。没有OCR重写、生成补字或二值化；模糊、过曝导致的原始笔迹信息丢失仍无法恢复。面向纸质文档，彩色照片或大面积底色画作不属于本轮质量保证范围。

## 新技术核查与取舍

- [SAM 2 / SAM 2.1](https://github.com/facebookresearch/sam2)：支持图像、视频的可提示分割。官方运行示例采用Python、PyTorch和模型权重，tiny模型也有38.9M参数；官方A100速度不能作为手机浏览器或微信耗时。
- [UVDoc](https://github.com/tanguymagne/UVDoc)：使用神经网格恢复弯曲文档几何，官方提供Python推理及模型。它主要处理弯曲展平，不能直接替代本轮纸面／桌面分离和光照恢复验证。

本轮落地的是端侧色度区域分割、候选区域验证和保色纸面恢复；没有集成上述神经模型，也不把聚类算法描述成语义分割AI。神经模型如后续接入，需要独立验证移动端运行时、模型体积、纸张专用数据与微信兼容性。

## 可重复验证

`scripts/evaluate-scan-v015.mts`从v0.14.0提取的`documentScan.js`与`scanGeometry.js`读取基线，只生成合成纸张、木桌、光照、铅笔、蓝笔和红章；通过`SCAN_V015_BASELINE_DIRECTORY`指定基线目录。合成结果和对比图保存在`outputs/`，允许随代码共享。

本轮附件在执行环境可读，已裁出相机取景区域作独立前后对比。图中已有绿色框、蒙版和圆点，会影响算法；测量依据人工标注纸角，只能说明这些截图上的结果，不能替代未覆盖UI的相机原照片或真机验收。用户附件、取景裁图与实图恢复结果仅留在本地scratch，没有加入GitHub或Sites发布包。

这不是总体数据集准确率。绿色界面覆盖仍可能进入截图裁图，新算法没有删除或重绘覆盖物；实际相机照片没有这些界面像素。少量背面透印、折痕和低信噪比内容仍可能留有残影，优先保留可能的真实笔迹。

新检测对贴边、横贯整页的强色彩内容可能保守判为不确定，沿用手动四角确认；纸张和背景同色、同纹理且没有完整可见边界时仍不能保证定位。
