# v0.9.1完整前端开发工程

2026-10-15。上一轮只同步了可运行预览，未满足用户下载完整源码继续开发的要求。本轮以已部署v0.9.1为基准，恢复了仓库根目录的开发工程，根目录版本、manifest和界面均为0.9.1。

## 源码与入口

- `src/pages/index/index.vue`：主页面，包含工作台、作业详情、批阅、反馈、订正、记录、成长、个人档案等Vue模板。
- `src/components/`：10个可编辑Vue组件，包含邀请码绑定、学校切换、任教班级和成员、班级学情、学生排名、个人成长、画布和评价编辑。
- `src/composables/usePrototype.js`：页面状态、导航、绑定、作业与批阅交互。
- `src/services/`：量表、教师与学生身份、任教范围、作业统计、成长与排名、示例数据、数据迁移、本地服务；`model.ts`保留当前前端状态类型。
- `src/platform/photos.js`：浏览器文件选择／data URL，以及微信选图／本地文件保存；统一限制1—6张、单张800KB。
- `src/styles.css`、`src/static/`：完整样式与虚构练习素材。
- `.nvmrc`、`package.json`、锁文件、Vite／TypeScript／uni-app配置和`启动原型.cmd`均在仓库根目录。

正常开发使用`npm ci`、`npm run dev`；检查使用`npm run type-check`、`npm test`；构建使用`npm run build:h5`和`npm run build:mp-weixin`。Sites静态包由`npm run build:site`从同一套源码生成到`dist/client/`。

托管仓库解除浅克隆后，完整历史共6个提交，均只保存静态发布内容，未发现Vue／TypeScript源文件或source map。GitHub此前也只保留旧工程。本次依据托管提交`bdbc80ba0dbf71fd264a26f7b5d298177320c125`恢复业务模块，将编译后的页面表达还原为Vue模板，重新整理模块边界、名称和样式，并补回微信平台分支。原始文件组织、注释和未保存的开发历史无法从发布文件完整取回；本工程是据线上行为恢复后可继续维护的源码。
