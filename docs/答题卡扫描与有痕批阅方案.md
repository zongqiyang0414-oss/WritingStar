# 自有答题卡快速扫描与有痕批阅方案

2026-11-02：用户明确数据集建设属于后期，当前优先快速得到清晰扫描件；后续希望AI在图片上画圈、波浪线等，并考虑采用商业产品常见的专用答题卡流程。本文件是方案与现状核查，不代表功能或真实AI接口已经接通。应用仍v0.22.0／manifest220，下一轮实际应用改动0.23.0；持续仅本地，不上传GitHub、不更新私有Sites。

## 现有基础与缺口

- `answerCards.js.cardDrawing`定义四个黑色方块、学生／页码二维码和固定书写格子；H5和微信共享模板绘制指令。可以使用自己的答题卡，不需要采用第三方专有卡片。
- `paperScanCapture.js`当前优先通用纸边，黑块仅保守辅助，未按模板中准确位置做优先配准。v0.22按完整照片原像素裁矩形PNG、提供常亮补光和连续换纸，不做透视拉正或增强。
- `WorkViewer.vue`当前只展示图片；`Review`保存总评、维度和建议，没有逐条图像批注。`aiReview.js`只对内置虚构作品产生示例结果，用户真实照片无真实模型结果。尚无后端／模型账号，不能将绘制示例当作真实AI精度证明。

## 推荐流程

1. **模板配置**：为每个模板版本明确页面宽高、四角标记坐标、正文区／题区及格子边界；学生码携带或可解析关联模板与页码。方向需由不对称标记或已验证学生码布局确定。旧版已打印卡片继续支持，不直接强制替换定位图案。
2. **快速采集**：前端小图优先识别已知模板定位点、验证布局、方向及页面完整性，稳定后自动拍摄；不确定时回退现有普通纸张流程。预览框坐标不能直接套到视野不同的静态照片，完整拍照图应复核。保持只换纸、不逐页确认、补光与停止／超时恢复。
3. **扫描输出**：教师立即查看高清裁剪件，保留颜色与细节；没有必要仅为批注强制重采样拉正。定位点位于纸内，必须按模板坐标推算目标范围，不能把标记中心当纸角或统一外扩猜边。模型确需正视图时生成分析副本，并保留其与展示图的坐标映射。
4. **识别与批阅**：OCR提供文字及位置／标识，AI返回对应文字的评价；也可接直接输出原文位置的作文批改服务。只有一段总评不足以精确落点。多次出现的相同文字需通过页码、行／格号或字符标识区分，不能只按文字搜索。方格适合一格一字，跨格／涂改仍需识别；书写结构评价还需查看真实字形，不能只靠转写文本。
5. **图上呈现**：程序根据结构化批注画错字圈、好句波浪线、编号短评，点击可看解释。跨行句子分别按每行位置绘制；底图与批注层分开保存，教师可核对、修改／删除后按现有审核规则给学生看。分享时再合成批阅图片，不能用生成式改图重画学生字迹。

## 批注定位约定

每条批注至少关联具体作品／页图版本、批注类型、目标格子或文字区域、原文与说明、审核状态。参考图的尺寸、方向及位置坐标系必须明确。若模型处理的是正文裁块、缩小图或拉正副本，结果需经过对应逆变换，才能落到当前裁剪展示图；不能直接用模型输入像素坐标覆盖手机屏幕。

拍照裁剪／旋转／重新上传后旧批注不能不加核对复用。图片与批注共用相同的显示缩放和留白计算，缩放、横竖屏、翻页及全屏时保持对齐。缺失位置、文本匹配歧义或识别不可靠的建议交教师核对，不凭空猜坐标或硬画圈。

定位点改善几何位置，内容判断是否正确依赖真实识别与模型；标准模板也不能保证失焦、弯曲纸张、潦草涂改都准确。需分别验收位置与评价，不能用合成图片或手工批注证明真实AI已实现。

## 最小落地顺序

先完成现有模板定位配准的快速扫描，并用真实打印填写作业验证连续拍摄、纸边、方向和细字；不增加数据集留存工程。之后接入能返回位置的真实中文手写识别／批阅能力，先做错字圈选、好句波浪线、编号短评三种；验证跨行、多页、重复词及教师审核后再扩展书写细节评价。相机采集与AI任务分开，不等待逐页批改才允许换纸。

具体后端／服务选型尚未确定；接口密钥应保存在服务端，前端绘制样例仅用于交互验收。当前没有调用收费接口、上传用户图片、训练模型或发布新版本。

## 核查依据

- [OpenCV 平面单应性](https://docs.opencv.org/4.x/d9/dab/tutorial_homography.html)：已知平面点可用于页面坐标映射；准确模板宽高可作为比例依据，折弯页不满足单一平面假设。
- [腾讯云作文批改Agent查询任务官方文档](https://cloud.tencent.com/document/api/866/128621)：官方中文示例提供`Origin`、`Message`、`Replace`、`SubType`与`Positions[].Position`，包含错别字及跨行优美句子的坐标。这证明存在适合图上批注的接口形式，不代表其在本项目、模板或用户真实作业上的效果已验证；具体坐标约定、可用配额及返回稳定性接入时另验。
