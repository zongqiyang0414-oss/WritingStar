# v0.16.0 · 扫描收片动画与触屏查看 · 2026-10-30

扫描成功后，处理好的真实图片从取景区缩小、飞入右下角缩略图，并以一次轻微弹动提示已收片。点击缩略图检查结果，可在扫描页直接双指放大、单指拖动；轻点进入平台全图预览。

## 交互与实现

- 自动拍摄时不等待动画，相机持续开启；手动拍摄等图片落入缩略图后进入结果页。新拍页需先调角时，确认处理后也有收片动画；相册批量导入沿用原顺序处理流程。
- 动画使用刚生成的扫描件，测量取景区与右下角缩略图的实际位置，在手机和桌面居中布局上计算落点。只改变显示变换，不另做像素处理或写入页面；页数仍以实际处理成功的页面为准。
- 进入查看、关闭相机、退出、切入后台或旋转时清理动画与定时器，避免迟到动画或重复计页。手动拍摄的动画取消后也不会再次切换页面。
- 微信使用cover-view／cover-image覆盖相机，H5使用普通图片层。微信实际摄像头层级与动画流畅度仍需真机确认。
- 新增ScanImageViewer.vue与scanImageViewport.js，支持1–5倍连续缩放，以两指中点为锚点。拖动边界按真实纸面尺寸计算，不能把整页拖丢；抬起一指后可平滑接着拖动。
- 翻页、重新处理或横竖屏变化恢复整页。缩放／拖动结束不误开全图；轻点调用uni.previewImage查看原扫描件，并提供同批图片列表。H5也可通过滚轮缩放。未恢复其他作品页之前移除的缩放工具栏。

## 验证

- 全部165项测试、类型检查通过。新增手势测试覆盖指下笔迹锚点、缩放／拖动边界、旋转复位以及两指转一指的连续性。
- H5与官方微信构建通过。微信运行产物1259837字节，小于2MiB；AppID、7份WXSS、整库文件存储、原生权限和选图生命周期检查通过。
- verify-weixin-scan.cjs新增编译后触摸事件检查：实际WXML的双指绑定可放大2倍，结束缩放不误触预览，稍后轻点调用微信全图预览；同时核查相机覆盖图标记。这是编译与事件适配检查，不是真机绘制验收。
- browser-regression-scan-feedback.cjs通过：Chromium真实触屏输入放大约3.06倍，拖动75／85px；动画有28个中间采样帧并落在实测缩略图中心，自动扫描不卸载相机。全图预览、旋转／翻页复位、手动收片与动画中进入查看的取消流程均通过。
- 原相册多选／调角续传／容量与保色回归，以及完整相机／同页锁／换页／学生码／归档／重复保护／统一提交流程均通过。开发机首份1932ms含约1.2秒稳定等待，不能作为手机时延承诺。
- 测试使用合成纸张与本地模拟身份；未使用真实学生素材。手机双指体验、微信相机覆盖层与流畅度仍待验收。
