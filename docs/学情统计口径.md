# 学情统计口径 · v0.4

2026-10-14。以下是本轮前端实现约定，后端统计接口仍需双方确认；不是已接入的服务端统计。

| 页面 | 范围与算法 |
| --- | --- |
| 班级趋势 | 当前班级全部作业按布置顺序排列。每项作业按每名学生最近一次已发布反馈求均分；书写和写作分别算，四舍五入到1位小数。显示该作业已发布人数/全班人数，不把未提交、未发布或其他班级学生计入。 |
| 全班排名 | 当前班级全部学生。每位学生的均分覆盖全部作业，每份作业只取最近一次已发布反馈；默认书写，可切换写作，按均分降序。相同显示均分并列（1、1、3）；未有成绩显示“—”并列在末尾，无名次。0分是有效分数。 |
| 搜索 | 对学生姓名做包含匹配并去掉首尾空格。先生成全班名次再筛选，搜索不重新排名。返回列表保留搜索词与排名类型；切班清空搜索。 |
| 个人成长 | 当前班级内指定学生的历次提交，按提交时间排列。每次提交只有已发布反馈才显示分数；包含订正旧轮次，待发布轮次显示空点、断线。下方成绩记录按最近提交在前排列。 |

书写与写作各100分，不合并为一个分数。均分排名与个人成长图使用不同的轮次口径：排名每份作业只计一次，成长图展示每轮已发布成绩，避免订正次数抬高排名。

图表使用固定0—100纵轴，作业/提交序号对应图下入口。点击图或图下入口查看作业与分数；超过6个成绩点可横向滑动。无已发布成绩显示空状态，一个成绩点仅显示点；没有成绩时不补0、不生成走势。

三级页面均属于【学情】：班级趋势→全班学生→学生成长，返回顺序相反。原“作业统计”保留，仍可进入作业详情。

实现参考：`src/services/analytics.ts`、`school.ts`及`src/components/ScoreTrend.vue`。图表采用[uni-app canvas API](https://uniapp.dcloud.net.cn/api/canvas/createCanvasContext.html)，H5交互与微信编译分别验证；微信真机显示仍须另验。

接入后端时需确认完整学期数据、布置顺序字段、分页与权限范围。分页列表不能冒充全班全量统计；正式学期筛选、加权方案及统计接口尚未约定。本轮不改变既有本机记录，不新造评分来补充折线。
