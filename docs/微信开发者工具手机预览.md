## 方式一：直接导入已构建的预览包

1. 下载最新 [WritingStar-v0.17.0-weixin-scan-20261102.zip](../outputs/WritingStar-v0.17.0-weixin-scan-20261102.zip)，解压到新的本机普通目录，例如 `D:\WritingStar-v017\`。不要直接在压缩包中打开文件，也不要与旧包覆盖混用；旧包缺少本轮独立Worker和比例修复。
2. 打开最新版稳定版微信开发者工具，使用有该小程序权限的微信扫码登录，选择“导入项目”。
3. 项目目录选择解压后的 `WritingStar-weixin-preview` 文件夹：这一层应直接包含 `project.config.json`、`app.json`、`app.js`。不要选择Vue源码根目录，也不要选择更外层的解压目录。
4. AppID应自动显示 `wxe3fefef9eaab17c3`，项目类型为“小程序”。如果要求选择后端服务，可选“不使用云服务”，本轮前端模拟体验不依赖云开发。
5. 导入后使用“普通编译”，点击“编译”。模拟器出现写字星后，点击右上角“预览”，等待生成二维码。
6. 用具有该小程序开发者／体验成员权限的手机微信扫码，打开手机开发版。若提示权限不足，请小程序管理员在微信公众平台“小程序 → 成员管理”添加对应微信。
7. 这一步不需要发布上线或提交审核。网页上的“登录”仍是原型模拟身份登录，不能据此认定真实微信账号／后端已接通。

检查包内 `build-info.json` 的 `sourceCommit` 可确认源码版本。AppSecret、上传私钥和个人开发者配置不在交付包中。

## 方式二：从GitHub源码自行生成

v0.17.0目前尚未上传GitHub，以下命令在本轮上传获准并完成后才能取得本轮修复；当前可直接使用上面的本地交付包。

Windows PowerShell／命令提示符中，在已有仓库目录执行：

```powershell
git fetch origin
git switch main
git pull --ff-only origin main
npm.cmd ci
npm.cmd run build:mp-weixin
```

使用项目 `.nvmrc` 对应Node版本（24.15.0）。首次切换若本机没有该分支，可先执行：

```powershell
git switch -c main --track origin/main
```

有未提交修改时先保存或提交再同步，不要用重置覆盖。构建完成后导入 `dist/build/mp-weixin/`，后续扫码步骤相同。请使用项目的 `build:mp-weixin` 命令，它会排除未使用的两张高清品牌原图（源码仍保留）、检查包体并校验AppID及WXSS；源码更新后重新构建，开发者工具里修改生成文件不会回写Vue源码。

## 手机验收

- 教师进入答题卡页，应同时看到“打印 / 下载此生 PDF”和“打印全班 · N页”。点击生成完整PDF，通过文件右上角菜单或返回后的“转发已生成 PDF”交给打印服务。每生2页、53人应为106页，单生导出2页；学生仅可导出本人。打印选择A4、原比例100%。生成时间随班级页数与手机速度变化。
- 通过教师／学生邀请绑定，体验作业、审核与反馈；只用示例图片或本人同意的测试素材。
- 原图一次显示一页，点击图片进入全图，可切换多页；横向照片不拉伸，分页后原图清晰可查看。
- 检查居中确认、“打回”取消／确认、已打回说明、学生一次重新提交与优秀作品入口。
- 微信端相册选图、拍照、图片预览、画布扫描处理和存储需要真机确认；浏览器连续自动扫描不等于微信已具备连续自动拍摄。
- 若出现 `app.wxss unexpected token *`，核对是否导入了本轮包及 `build-info.json`；如有新报错请保留完整文件名／行号和基础库版本。网络 `ECONNRESET` 与WXSS编译错误应分别排查，不要通过改AppID或关闭鉴权处理。

最新存储修复包将整库记录保存在小程序本机文件，原Storage键只保留小索引；旧记录自动兼容读取。首次编译、绑定、进入完整练习数据后不应再出现单条Storage过大提示。展示设置位于应用下方，滚至页面底部查看。不要为升级重置数据或清除缓存。
