# 作业扫描 · 2026-10-29

教师代交和学生提交均从“扫描作业”进入独立扫描页；新增页数按当前提交剩余页数计算，合计最多6页。连续扫描属于当前选定学生的同一份作业，不自动识别学生、扫码分配或提交到后端。

## 使用流程

1. 允许相机权限，将完整纸张放入画面，四周留一些背景。识别到四角后显示绿色多边形，点击拍摄。
2. 开启“自动扫描”后，纸张持续稳定约1.2秒才拍摄。成功后锁定当前页，移开旧纸再放下一张即可继续；未识别出换页时可点击“已换好下一页，继续识别”。短暂遮挡、整体曝光变化、相机中断不直接触发连拍。
3. 每次拍摄都在高清照片上重新检测四角，避免把预览帧比例直接套到照片。找不到完整边缘时进入调角页，不默默保存原照片。
4. 处理包含四点透视矫正、裁去纸外背景、局部纸白校正及灰度增强。保留连续灰阶，不用OCR重绘或生成笔迹，不生成AI分数。点击缩略图检查，可调整四角、重新处理、删除和继续扫描。
5. 完成后把处理后的JPEG添加到原提交页，再检查页序并提交。扫描自动压缩至现有单页800KB限制内；处理或保存失败显示错误，不以原照片冒充扫描件。

原“选择作品照片”入口保留，仍为普通原图选取；扫描页“从相册扫描”走同一套检测、调角及处理流程。

## 微信接入

- 独立`pages/scan/index.vue`使用后置原生`camera`、`CameraContext.onCameraFrame()`与`takePhoto({quality:'high'})`。帧分析约每300ms一次，长边缩至256像素，不把原始缓冲放入Vue状态或提交数据。
- 边框由独立Canvas 2D生成透明图，通过`cover-image`覆盖原生相机，避免普通DOM/SVG的原生层级问题。相机区按cover映射，调角区按contain映射；页数、提示、窗口变化后重新测量区域。
- 微信使用Canvas 2D节点：输入长边最多2200，输出长边最多1800；工作画布移出可视区，不使用`display:none`。H5的DOM canvas、video、getUserMedia通过条件编译排除在微信包之外。
- 先处理微信隐私授权与`scope.camera`。拒绝后可去设置或从相册扫描；不支持相机帧时关闭自动模式，保留拍摄后识别和调角。缺少Canvas 2D时明确报错，不生成假结果。
- 隐藏、切后台、退出或打开检查页时停止帧监听并卸载相机；回到前台点击开启。过期帧、拍摄、处理与保存回调不添加扫描页。浏览器也停止全部媒体轨道。
- 完成时用`FileSystemManager.copyFile`生成应用目录中的持久副本，全部成功后回传。中途失败或取消只删除本次副本，保留临时处理图供重试，避免`saveFile`移走临时图。退出清理本次临时原图、处理图和边框图；已添加到提交草稿的文件继续由现有作品流程使用。
- `manifest.json`保持AppID `wxe3fefef9eaab17c3`，增加相机用途和隐私检查声明。正式运行前需在微信小程序管理后台维护并发布实际《用户隐私保护指引》，按微信要求声明相机、相册等相关接口用途；仓库配置不能替代后台配置。基础库建议使用当前稳定版，至少具备CameraFrame与Canvas 2D；真机再做能力验证。

## 能力与验证边界

本轮为本机亮度／边缘轮廓检测，不调用云端或商业扫描SDK。完整纸张、均匀光线、背景有对比度时适用。白纸贴近白桌、强阴影、反光、遮挡、多张交叠、卷曲纸张或复杂浅色背景可能漏检／误框，需调角或重拍；四点透视不能展开折痕或弯曲纸面。拍摄时避免出框，处理后核对浅铅笔、页边、二维码和批注。

自动验证使用合成像素／合成相机流与接口桩，覆盖倾斜、阴影、灰阶、稳定计时、换页锁定、帧中断、授权、保存回滚、学生匹配和布局。它们不代表用户参考图已跑过实机扫描，也不代表iOS／Android摄像头和微信覆盖层已验收。

真机重点：首次授权与拒绝恢复；预览旋转及cover对齐；Canvas照片方向；透明边框；手动与自动连续扫描；笔迹和纸边完整；后台恢复；退出相机指示灯熄灭；保存重试；提交后重启小程序仍可读图。正式图片上传、存储期限及跨设备访问继续由后端协作者接入。

## 源码与验证入口

- `src/pages/scan/index.vue`：界面、调角、页面和相机生命周期。
- `src/platform/scanner.js`：两端相机／画布、权限、选图、文件与保存事务。
- `documentScan.js`、`scanGeometry.js`：检测、映射、透视及增强；`autoScan.js`：稳定计时、换页、防重复。
- `tests/document-scan.test.ts`、`scan-weixin.test.ts`、`navigation.test.ts`：算法、微信分支和回传。
- `scripts/browser-regression-scan.cjs`：先构建H5再运行；`WRITINGSTAR_CHROMIUM`可指定浏览器，`WRITINGSTAR_SCAN_URL`可指向本地开发服务。
