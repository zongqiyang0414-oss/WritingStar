# v0.17.0 方圆格作文模板

用户指定`方圆格作文空白模板_前后两页.pdf`为固定作业用纸，并要求自动生成标题与学生二维码。本轮将原PDF作为两页底版接入网页、微信预览以及单生／全班打印；不把附件内的纸面书写提示当作开发指令。

## 排版与尺寸

- 原文件1191×842点，A3横向。底版按2倍渲染成2382×1684 PNG（153213／135472字节），原PDF与生成脚本一并入库，可重复生成；运行时不引入PDF解析库。
- 首页左侧：作业标题最多三行，学生信息自动填入班级／姓名／学号并留分数空栏；二维码在信息下方。第二页同样的信息与该页二维码位于右侧空白栏。二维码含原WS1学生卡ID、页序和总页数，校验／归档规则不变。
- 方圆格、思维导图、提纲和原定位标记保持；写作要求只占空白栏，过长省略并提示查看学生端全文。新作业保持默认两页，界面不再提供与固定两页底版相冲突的页数选择；历史1–6页卡不迁移、不换ID，第2页以后用续页底版并保留真实页码。
- 网页`@page`为A3 landscape、420×297mm；微信流式PDF传入1190.55×841.89点，通用PDF写入器的旧调用仍默认A4。打印说明为A3横向、100%，双面短边翻转。

## 实现与验证

- `answerCards.js`统一生成绘制指令；底版加载失败会报错，不生成缺少底版的白纸。网页异步载图有缓存和失败后重试，微信用`getImageInfo`取得本地路径。切页／切学生的预览用请求序号及微信绘制队列避免旧图覆盖。
- `scanCode.js`先尝试横向模板的两处二维码区域，再保留旧竖版及全图回退。没有改变身份权限、单次提交、重新提交许可或AI批阅流程。
- `npm test`：165项全部通过，包含全班106页逐页打印／微信PDF、原图保留、失败清理和新A3页尺寸；`npm run type-check`通过。
- `npm run build:site`与官方`npm run build:mp-weixin`通过。微信产物1549496字节，AppID、WXSS、超过1MiB整库文件保存／重读、打印入口、扫描授权与手势编译检查通过。
- `scripts/browser-regression-fangyuan-template.cjs`：真实Chromium完成登录、发布作业、两页切换、单生2页打印、A3样式核验；识别网页两页PNG与微信画布适配生成的4页JPEG，6个码全部准确匹配学生及页码。PDF共4页（两名虚构学生），每页1190.55×841.89点，1841050字节；临时JPEG峰值为1。无页面错误。
- 已人工查看首页、第二页和50字以内长标题产物，文字／码不覆盖写作区。示例学生均为虚构；截图及PDF可入库。微信原生文件菜单、真机画布与实际打印效果尚未验收；浏览器适配验证不代表真机已通过。
- 构建最初因沙箱不开放网络接口查询而发生`uv_interface_addresses`，使用工具允许的网络能力运行原构建命令后通过，没有修改应用或构建器规避问题。
