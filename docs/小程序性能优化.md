## 已处理的开销

- `MockService.snapshot()` 提供稳定的只读快照，页面使用 `shallowRef`。返回前台时，数据未变化就沿用原引用；保存时仅复制账户、作业或当前作品等发生变化的分支，避免整库 JSON 深拷贝。存储成功后才替换状态，保存失败保留原数据。
- 按作品数组缓存最新提交、最近已发布提交和学生历史索引。作业计数、学情和成长查询复用索引，消除学生与作业循环内反复扫描、排序全部作品的开销。可变数据调用方仍即时查询，防止读到过期结果。
- 页面通过 `pageModels.js` 给组件提供展示摘要。排名搜索只过滤已有排名；截止时间更新只调整进行中状态；成长摘要、曲线和历次成绩共用同一次历史查询。点击摘要后按 ID 查回原学生或作品，并继续校验范围。
- 图表首次挂载只测量一次，合并同轮成绩、选点和图例变更的绘制；连续窗口变化合并测量。卸载时取消定时器、浏览器绘制帧，并忽略延迟返回的布局查询。
- 微信产物移除仅供桌面 H5 展示的左右介绍区及重复展示工具；作品记录缩略图启用懒加载。

评分仍沿用两套百分制；未发布成绩留空，订正保留旧作品和已发布反馈。存储键及既有数据格式继续兼容。

## 微信真机复测

1. 运行 `npm run build:mp-weixin`，将 `dist/build/mp-weixin/` 导入微信开发者工具，填写自己的 AppID。云端受限环境构建可加 `CI=1`，跳过编译器的更新检查。
2. 保留已有存储，用手机扫描本次构建的预览码。教师绑定后，依次切换工作台、学情、全班排名、个人成长、我的和班级成员；切换学校／班级，输入姓名搜索，并逐级返回。
3. 在较旧或中低端手机上重复上述操作，分别观察首次进入与再次进入。使用开发者工具／真机调试的性能面板记录切页时的脚本耗时、长任务、视图更新及卡顿位置；比较前后版本时使用相同手机和数据。
4. 保存草稿、发布反馈，再切学生查看、提交订正、切后台再回来，检查记录、未发布权限和页面内容及时更新。滚动作品记录，确认缩略图正常加载。

反馈时提供手机型号、微信版本、卡顿路径及首次／重复进入是否一致；如有性能面板记录，可继续针对实际长任务定位。编译、自动测试和 H5 浏览器检查均不替代微信真机验收。
