# v0.17.0 · 小程序拍后处理与纸张比例

2026-11-02（北京时间）。接续 GitHub main 的 v0.16.0，版本升级为 0.17.0／manifest 170。线上发布及源码提交以[交付状态](云端交付状态.md)为准。

## 原因与修改

- 微信预览使用独立的小程序运行时。此前照片校正、学生码读取、去阴影和锐化均在页面逻辑线程执行。`scanProcessor.js` 现在复用一个原生 `wx.createWorker`，把拍后像素计算交给独立线程；`src/workers/scan.js` 由官方微信构建流程打成自包含脚本，并在 app.json 中登记。没有把大图变成普通数组或经过 Vue／setData 传输。
- 先用四字节 ArrayBuffer 验证双向通信，旧版 JSON 消息、创建失败、崩溃或超时自动回退同一照片的分段处理。后台／离页终止计算，不接收迟到结果；销毁时释放线程。相机拍摄、扫描页相册和收件箱旧批量导入均接入；相机预览的纸边检测仍在页面运行。
- 照明场横向插值按采样格行缓存；锐化缓存三行亮度，减少逐像素重复计算。保留 RGB 保色、双线性透视采样、输出长边上限、原照片及取消处理，没有通过降低清晰度换速度。
- 原输出宽高直接取照片中两组纸边的最大长度，斜拍会把透视缩短写进成片。现在根据矩形正交方向恢复纸张比例：假设相机像素等距、主点在图像中心；可靠时估计焦距，单轴／弱透视时使用保守相机估计。自动结果仍依赖四角和拍摄条件。
- 调角页新增“纸张比例”：自动估算、A4／A5竖版、A4／A5横版、正方形。结果页“调整边角与比例”可从保留原图重新处理当前页，选择跟随该页保存，不增加页数。已知纸张时选明确比例，避免估算误差。

## 手机验收

1. 重新解压本轮微信包，导入新目录，编译后“预览”；不要继续扫旧包的二维码。与原私有网页用同一照片比较处理速度及细字。
2. 分别测试实时拍摄与相册、普通文档与纸卡收件箱；处理时切后台后回来，确认不会重复收页或恢复旧结果。
3. 斜拍A4竖纸和横纸，检查字、方格、圆形是否变形。必要时“调整边角与比例”，框准真实纸边并选对应方向，再确认。
4. 检查蓝笔、红章、浅铅笔和细线；多张相册中修改一页比例，确认其他页、学生码和页序不变。

本轮没有微信开发者工具或手机真机可用，iOS／Android实际耗时、二进制通信能力、内存占用与极端拍摄效果仍待上述验收。Worker主要减少主线程阻塞，微信运行时、解码／JPEG和消息复制仍可能影响总耗时。自动比例不是相机标定：极斜角、错误四角、裁切后照片、镜头畸变或弯曲纸面仍可能需要指定比例或重新拍摄。未取得本轮用户原图，不声称其照片已实测。
