## 继续云端开发

GitHub 源码和预览已就绪，Codex 云端开发环境仍需在产品界面创建。本次没有创建该环境，上传仓库本身不会自动创建环境。

在网页或桌面端选择 Work in → Cloud → Select environment → Create environment，选择 WritingStar，设置下面的安装和检查命令，完成并发布环境。之后手机可选择该环境继续提出修改。[OpenAI 官方云端说明](https://learn.chatgpt.com/docs/cloud)

- Node：`.nvmrc` 中的 24.15.0。
- 安装：`npm ci --no-audit --no-fund`。
- 检查：`npm run type-check`、`npm test`。
- 构建：`npm run build:h5`、`npm run build:mp-weixin`。
- 不需要后端或 AI 密钥；读 `AGENTS.md`、README 和验收表后继续开发。

后续默认在本机修改源码及验收表并运行对应检查。只有用户明确要求上传时才同步并提交GitHub，明确要求线上更新时才构建并更新私有Sites。当前GitHub Actions只自动检查和保存产物，**推送不会自动发布Sites**，也没有每个PR的独立预览。云端会话需要可调用Sites工具才能直接更新该预览。
