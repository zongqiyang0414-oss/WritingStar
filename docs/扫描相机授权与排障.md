## 微信小程序怎么使用

1. 在新版开发包中，从作业详情进入扫描收件箱，点“开启相机扫描”，再点扫描页里的“开启相机”。现在由实际点击触发隐私与原生相机授权，不在页面加载时自动请求。
2. 微信出现隐私或摄像头授权提示时，阅读后选择允许。首次尚无 `scope.camera` 条目时，会先挂载原生相机，由微信显示授权提示；不要求先在权限列表里手动找出一个尚未请求的权限。
3. 若此前拒绝了本小程序的摄像头授权，页面显示“打开小程序权限设置”，点它进入微信的授权设置，再允许摄像头并重试。此入口不是截图中的使用记录列表。
4. 若手机系统禁止微信使用相机，页面显示“打开手机授权设置”。iPhone也可在系统“设置→隐私与安全性→相机”中检查微信；不同系统版本可能在“设置→应用→微信”中显示。没有微信条目时，应先通过新版扫描页实际触发相机请求。
5. “从相册扫描”独立于小程序摄像头权限；只选择一张照片时不会请求 `scope.camera` 或“保存到相册”权限。新基础库用 `chooseMedia`，旧版保留 `chooseImage`。也可选“使用系统相机拍摄”，拍摄后走相同的裁切、矫正及增强。

如果提示是“小程序隐私配置未完成”或详情包含 `privacy` / `scope is not declared`，手机授权开关不能代替后台配置。需要小程序管理员登录对应 AppID `wxe3fefef9eaab17c3` 的微信公众平台，在“设置→服务内容声明→用户隐私保护指引”中按平台当前界面补充并发布实际使用的摄像头、选中的照片或视频信息等用途。开发者工具可检查相应隐私接口配置；真实后台状态无法仅靠源码中的manifest字段代设。

新页面的“复制错误详情”会保留微信返回的失败原因，便于区分手机系统权限、小程序拒绝、隐私配置和其他接口失败。正常图像处理错误也保留原意，不再一律解释为权限问题。

## Chrome怎么授权

- 通过HTTPS完整网址打开；手机访问电脑的HTTP局域网地址通常不能获得实时摄像头权限。`localhost`的例外仅指浏览器所在设备本身。
- 在网站提示中允许相机。如果已拒绝，查看地址栏的相机／网站权限入口；iPhone上的Chrome还需在iPhone设置中允许Chrome使用相机。Google官方说明指出，系统权限关闭时，网页可能根本不会出现授权提示：[Chrome摄像头权限（iPhone／iPad）](https://support.google.com/chrome/answer/2693767?co=GENIE.Platform%3DiOS&hl=zh-Hans)。
- 嵌入页面或站点的Permissions-Policy禁止相机时，网页不能自行绕过限制。新版会明确指出这一原因，提示直接在Chrome新标签页打开完整网站，系统相机／相册选图入口仍可独立使用。
