## 两端固定操作

开始工作：读取`AGENTS.md`和本文件；在保留个人修改的前提下同步`main`。工作区干净时可执行：

```sh
git pull --ff-only origin main
```

本机预览：依赖可用后执行`npm run build:mp-weixin`，微信开发者工具导入生成的`dist/build/mp-weixin/`。开发者工具直接修改生成文件不会回写源码，下次构建会覆盖；修复应回到`src/`或构建脚本。

每个微信构建包含`build-info.json`，记录源码提交号、是否带有未提交修改、AppID、生成时间和本轮自动检查名称。用于辨认旧包／新包；从无Git元数据的源码包构建时，提交号可能为空。它不包含密钥，也不表示真机验收通过。
