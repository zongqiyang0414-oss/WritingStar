# v0.19.0 · 连续自动收片与成片形状

2026-11-02（北京时间）。用户确认v0.18不再卡住，本轮希望开启自动扫描后教师只需更换文档，不再逐页确认；同时反馈选择横版／方形并确认后，最终扫描件仍无可见变化。

按用户当前指令，仅本地修改与微信包交付，暂不上传GitHub、不更新私有网页。

## 使用流程

开启相机并保持自动扫描开启→纸张放稳后自动收片→更换下一张→继续自动收片。正常流程没有“已换好下一页”的确认按钮，整批扫完再点一次“结束扫描”。原有每批60页限制保留。

照片边缘检测不确定时，自动模式保留完整画面、标记结束后可检查，继续取景；不弹出调角页。不确定全图不读取学生码，避免误把背景其他纸张的码归给当前页。结束后可选中待检查页，调整边角重新识码；收件箱仍按原规则确认未知学生／缺页／重页。主动手拍、相册和主动调角仍可手动编辑。

原“纸张比例”改为“成片形状”，用于决定最终扫描件的宽高；普通作业默认“自动保持纸张形状”。A4／A5竖版为窄长、横版为宽短，正方形宽高相等。请按真实纸张选择，选错形状会改变字迹的宽高。调角原图用于定位纸边，右侧新增实际裁剪的成片小预览，选项改变时立即更新；确认后替换当前页，不增加页数。

## 实现

- 旧同页锁只靠192个灰度采样点，统一版式或只变学生码的纸卡可能差异太小。新增24×32个局部墨迹密度单元；保持背景移除、稳定等待、同页锁和曝光保护。细节变化以相邻帧跟踪，几何／粗采样仍用固定候选锚点，避免亚像素边框收敛反复清零。
- 已成功解析并校验专属学生码的纸卡允许识别较小的变化；自动成片阶段再按完整学生码拦截已收页。通用网址等其他二维码不能开启此身份路径，也不能让不同学生的作品被当作重复页丢弃。未知码与不确定页保留，归档仍由现有服务核对。
- 自动照片不确定时不使用猜测四角强裁剪，输出标记corrected:false；页面与收件箱提示检查，不伪称已自动校正。完整图像处理、取消／超时、原生帧背压和无浮动原生收片层沿用v0.18。
- 形状小预览使用独立画布和600px读图／320px裁剪，不与正式成片共用工作画布。变更合并执行，迟到预览丢弃并清理；取消后不写回其他任务。
- 微信导出等待画布绘制回合，并串行执行JPEG生成／复制。每次编辑输出复制为独立临时文件路径，避免原生临时URI复用或图像缓存让旧结果留在画面；旧成片在新图成功后再替换。取消会释放排队等待，保留已扫描页面。

这些修改覆盖事件传递、输出尺寸和图片更新路径，当前没有iPhone14 Pro Max执行环境，不能断言已证实其旧图现象的唯一根因或真机效果。

## 验证

- 178项测试、类型检查通过。包含同版作业细小字迹差异、曝光／平移／短暂遮挡不重拍、连续跟踪漂移与学生码小变化；原业务、权限、存储与比例测试保留。
- H5与官方微信构建通过。实际编译的小程序在原生API模拟下连续收3页，不点确认；同页不重复；不确定照片保留完整画面并继续相机，结束返回corrected:false和空码。
- 小程序编译后实际调用picker事件，检查横版和正方形的小预览／正式画布导出宽高、每次编辑的新路径、旧图清理及页数保持；模拟原生导出反复使用同一临时URI，成片仍有独立路径。通用网址二维码存在时三张不同作业全部保留。
- 浏览器实际选择成片形状、等待小预览、确认并读取JPEG自然尺寸：竖版568×803、横版803×568、正方形803×803。相册多选页序、颜色、暂停／恢复与迟到结果不收页通过。[形状预览](../outputs/scan-ratio-v019-20261102.png)。
- 浏览器实际纸卡通过同页停留3.2秒后直接换下一页、放回已收学生／页码不重复加入、相机保持开启、学生码归档、手动模式及60页收件箱。[自动扫描](../outputs/v019-scan-auto-20261102.png)、[结果](../outputs/v019-scan-result-20261102.png)、[收件箱](../outputs/v019-scan-inbox-20261102.png)均为合成素材。网页收片动画、双指缩放／拖动、原生全图预览与反馈取消回归通过，[放大查看](../outputs/v019-scan-zoom-20261102.png)。

手机验收：解压v0.19包到新目录重新导入并预览；先用3—5份同版作业连续更换，过程中不点确认；最后一次结束。主动调整同一页为横版／方形，比较小预览与最终图形状，再按真实纸张恢复自动／对应A4方向。新包包含v0.18的iPhone操作恢复，仍需用户真机复测。内容完全相同、无学生码的纸张需要让镜头看到换页过程；仅靠静止画面无法区分两张相同纸。
