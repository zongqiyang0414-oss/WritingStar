## 启动

建议采用 `.nvmrc` 中的 Node 24.15.0。仓库首次安装使用 `npm.cmd ci`（Linux 云端使用 `npm ci`），按 `package-lock.json` 重现依赖。

在本目录打开 PowerShell：

```powershell
npm.cmd ci
npm.cmd run dev
```

打开 <http://127.0.0.1:5173/>。依赖已安装时直接执行第二行，或双击本目录的 `启动原型.cmd`。预览服务需要保持运行；关闭服务后链接不再可用。同一地址、同一浏览器中的演示数据会保留。

## 推荐体验顺序

1. 默认教师身份，在工作台切换两个任教班级，查看各自进行中与已截止作业；首页数字仅展示当前班级进行中作业的状态数量，不能点击跳转。
2. 布置作业时确认班级并发布，检查作业只进入对应班级。
3. 打开作业详情，按未提交、待批阅、已完成查看名单；进入待批阅作品，切换书写/写作评价，修改五维分数或总评，保存草稿。
4. 切换家长/学生查看任务，未发布草稿不显示评分；回到教师发布反馈后，学生可查看两套百分制和完整五维。
5. 学生点击“按建议，再写一次”，选择照片、调整页序并提交；教师端该生重新归入待批阅。需使用练习素材时，在应用外“展示设置”装载两页作品；失败开关也在这里。
6. 教师切换底部“学情”，先查看班级书写与写作平均分折线；点击“查看全班学生学情”，搜索姓名并切换两套均分排名；点击学生姓名查看个人成长图和历次提交成绩。逐级返回保留搜索与排名类型；各层都属于学情，原作业统计保留。
7. 在学生“记录”中查看两版作品：订正不覆盖旧作品，未发布版本不显示评分。家长与学生仍固定关联小禾。
8. “展示设置 → 重置原型数据”恢复初始状态；确认后会清除当前记录。正常版本更新会迁移原有单班级数据，无需重置。

## 教师工作台与统计口径

- 作业以班级为单位发布；切班同步切换作业、学生和统计范围。
- 工作台分“进行中的作业”与“已截止的作业”。数据面板只统计当前班级进行中作业，三张卡片为静态数字，不承担导航。
- 未提交、待批阅、已完成按每位学生每份作业的最新提交判断；新提交和订正均归待批阅，反馈发布后归已完成。
- 学情页覆盖当前班级全部作业，分别查看学生与作业统计。均分取每位学生每份作业最近一次已发布反馈，未发布草稿不参与；没有已发布分数时显示“—”。书写与写作各自统计。
- 班级趋势按作业顺序展示该作业的班级均分与参与人数；全班排名可搜索并切换书写/写作。个人成长按提交时间保留每轮已发布成绩，包括订正。无成绩留空，一个成绩点不生成连线；纵轴默认60—100、5分间隔，低分自动扩展下限。全部成绩点适配宽度显示，图下圆圈序号换行。详细口径见[学情统计口径](docs/学情统计口径.md)。
- 本机数据结构升级为包含班级关系的schema 2；原有作业、作品、反馈和订正记录保留并归入原班级。迁移与统计的验证范围以验证记录为准。

## 工程结构

- `src/pages/index/index.vue`：手机界面及页面切换。
- `src/components/ReviewEditor.vue`：双写评价编辑。
- `src/components/ClassSelector.vue`、`ClassStatistics.vue`：班级选择与学生、作业统计。
- `src/components/ScoreTrend.vue`、`StudentRanking.vue`、`StudentGrowth.vue`：成绩折线、全班排名、个人成长。
- `src/composables/usePrototype.ts`：界面状态与交互。
- `src/services/model.ts`、`rubric.ts`：数据合同和唯一评分配置。
- `src/services/mock.ts`：模拟业务服务；页面通过统一入口调用。
- `src/services/index.ts`：本机存储适配；后续真实 API 在服务层接入。
- `src/services/school.ts`、`migration.ts`：班级统计口径和旧数据升级。
- `src/services/analytics.ts`：班级趋势、均分排名与个人提交成绩。
- `src/services/trendLayout.ts`：图表纵轴、刻度与全部成绩的坐标。
- `src/services/seed.ts`、`src/static/`：虚构示例数据与原创 SVG 界面插画。
- `src/services/classPractice.ts`：四（1）班一次性追加的作业、自然姓名与双评分，不覆盖已有作品。
- `tests/workflow.test.ts`：评分、发布、提交、历史和故障的必要检查。
- `tests/school.test.ts`：班级隔离、截止边界、订正统计及旧数据迁移检查。
- `tests/analytics.test.ts`：趋势去重、排名与搜索、成长轮次及班级隔离。
- `tests/classPractice.test.ts`：填充范围、成绩合法性、原记录保留、幂等与保存失败恢复。
- `tests/trendLayout.test.ts`：5分刻度、低分完整显示与全部成绩坐标。
- `原型更新与验收表.md`：每版新增/修改清单及用户反馈。
- `outputs/验证记录.md`：逐版开发验证范围；同目录保留各版预览截图。
